# 参考来源

本目录包含产品经理系统在设计过程中参考的外部 Skill 文件副本。这些文件**不是运行依赖**，仅供离线查阅设计灵感和方法论来源。

所有文件均来自开源项目（MIT 协议）。

## 目录

| 目录 | 来源 | 借鉴内容 |
|------|------|---------|
| `superpowers/` | [obra/superpowers](https://github.com/obra/superpowers) | Sub-agent 驱动开发、系统化调试、代码审查流程 |
| `andrej-karpathy-skills/` | [forrestchang/andrej-karpathy-skills](https://github.com/forrestchang/andrej-karpathy-skills) | 简单优先、精准修改、目标驱动编码准则 |
| `anthropics-skills/` | [anthropics/skills](https://github.com/anthropics/skills) | 前端设计、画布设计方法论文档 |
| `code-review-skill/` | 本地收集 | 多技术栈审查规则 |
| `ui-ux-pro-max-skill/` | [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | 设计系统、品牌规范 |
